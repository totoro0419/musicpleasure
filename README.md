# MusicPleasure v2.1 — Invidious-only Music PWA

音楽とYouTubeの歌ってみたを、**Invidious API専用**で検索・音声再生するReact/TypeScript/Vite PWAです。

## 再生基盤

- 最優先接続先はAndroid実機で再生成功の報告があった `https://yt.chocolatemoo53.com`。
- 代替候補は `https://eu.yt.chocolatemoo53.com`、`https://invidious.nerdvpn.de`、`https://inv.nadeko.net`、`https://invidious.tiekoetter.com`。
- `/api/v1/search`、`/api/v1/videos/:id`、`/api/v1/playlists/:id`、`/api/v1/channels/:id/videos`、`/api/v1/search/suggestions` を利用。
- `adaptiveFormats` の音声を優先し、利用可能な場合は音声入り `formatStreams` を代替として試します。
- 複数インスタンスの評価、切り替え、失敗の一時除外、音声再生成功の独立記録に対応。
- YouTube IFrameとMP3変換サーバーは使用しません。

## 機能

- 楽曲・歌ってみた・チャンネル検索、URL登録、検索候補
- キュー・連続再生・シャッフル・リピート・位置保存・Media Session
- プレイリスト作成・編集・複製・結合・一括操作・Undo / Redo
- 関連動画・検索・お気に入り・履歴を利用した6モード推薦と無限ラジオ
- コピー＆ペーストの一括登録と候補確認、YouTubeプレイリスト全ページの自動取得・進捗保存・中断再開
- 自然な日本語による作成・名前変更・追加・削除・移動・結合・複製・並べ替え・条件抽出・重複整理（変更プレビュー、Undo / Redo）
- ローカル音声の複数取り込み、内容のハッシュによる重複排除、容量確認、曲情報編集、音声の書き出し・削除
- IndexedDB、JSONバックアップ、保存音源の完全オフライン再生、PWA更新
- 従来の保存済みライブラリを保護し、旧再生エンジンの設定のみを移行

## 保存した音楽を聴く

「ライブラリ」→「保存した音楽・音声取り込み」から、自分が所有する音声ファイルを複数選択できます。MP3 / M4A / AAC / Ogg / WAV / FLAC / WebMのうち、そのブラウザがデコードできる形式に対応します。1ファイル128MBまで。MP3のID3テキストとファイル名から曲情報を補い、再生時間はメディアから読み取ります。読み取れない曲情報は編集できます。

音声の実体はIndexedDBの独立ストアへ保存し、通常の曲情報やJSONへ埋め込みません。保存済みの曲をオンライン曲と同じプレイリストへ登録できます。通信がないときはオンライン曲を飛ばして保存音源を再生します。最初にオンラインでアプリを開き、PWAの準備を済ませてください。

「保存が許可されたHTTPS音源」では、利用許可の確認後、取得元がCORSで許可する音声ファイルだけを取り込みます。YouTubeストリームを恒久保存する操作は提供しません。JSONバックアップはメタデータのみです。音声は「音声を書き出す」で別に保管してください。ブラウザデータの消去は音源も消します。保存保護の許可・上限はブラウザに依存します。

プレイリストのページ取得は1ページずつ進め、毎ページ保存します。途中失敗・同じページの再送・総件数未達を「完了」と表示しません。APIが返す非公開・削除済み項目は区別し、APIが返さない曲の内容は推測しません。

日本語操作では上の登録先リストが操作対象です。例：「通学」を作って / 名前を「夜」に変更 / 「曲名」を追加 / お気に入りを「別のリスト」へ移動 / アーティスト順に並べ替え / 5分以上を抽出。理解できない指示・複数対象の曖昧さ・プレビュー後の別の変更は実行を止めます。外部AIや有料APIは不要です。

事前読み込みは次曲1曲を優先し、短い音声バッファを再生時に再利用します。保持上限は3音源。古いキューの取得は中断し、期限付きURLを再評価します。通信量節約設定を尊重します。診断画面の開始時間は実際のメディア時刻の進行を確認して記録し、500msの測定間隔を含む上限寄りの値です。

## 検証と既知の制約

検索APIの成功や音声URLの取得成功は、実際の音声再生成功を意味しません。動画ごとの取得拒否、HTTP 403、CORS、音声形式、公開インスタンスの停止によって再生できないことがあります。すべてのYouTube投稿の再生は保証しません。

単体・模擬音声テストと、モックなしの実サービス試験 `tests/live.spec.ts` は区別します。実サービス試験では10曲の再生位置の進行、異なる3曲の曲終了による切替、無限ラジオを独立して確認します。`tests/offline.spec.ts` は元のPCMテスト音源を保存し、通信遮断・再起動後の3音源の終了切替を確認します。画面サイズを変えたChromium試験は、Android・Windows実機の検証とは区別します。
